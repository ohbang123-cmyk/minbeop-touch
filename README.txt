민법 터치 문제풀이 — iPhone PWA

구성
- 네가 준 문제 260910.pdf에서 추출한 원문 533개 문항을 내장
- 빈칸이 있는 407개 문항, 총 855개 빈칸을 빈칸 단위로 진행
- 한 문장 선택 → 1번째 빈칸 → 2번째 빈칸 → ... → 문장 종료
- 문장이 끝나면 다음 문장은 문제은행에서 무작위 선택
- 같은 문장은 전체 문장 순환이 끝나기 전에는 다시 나오지 않도록 셔플 큐 사용
- iPhone 화면/터치용 UI
- AI 4지선다 생성 기능: OpenAI API 키를 앱 설정에 입력하면 현재 빈칸마다 ①②③④ 생성

iPhone에서 앱처럼 쓰는 방법
1) 이 폴더를 HTTPS로 서비스한다.
2) iPhone Safari에서 주소를 연다.
3) 공유 버튼 → '홈 화면에 추가'를 누른다.
4) 홈 화면 아이콘으로 실행하면 앱처럼 standalone 화면으로 열린다.

주의
- ChatGPT 유료 구독과 외부 OpenAI API 사용은 별개입니다.
- 현재 버전은 개인 테스트용이라 API 키를 브라우저 저장소에 넣을 수 있습니다. 실제 배포용으로는 서버 중계 방식이 더 안전합니다.
- PDF 원문의 줄바꿈/공백은 휴대폰 표시 과정에서만 일부 정리되며, 문장 내용 자체는 원문을 유지합니다.
