민법 터치 — GitHub 업로드용 초안

이번 버전에서 적용한 기능
1. 전체 문제를 무작위로 출제하되, 한 바퀴 동안 같은 '문장 문제'를 다시 내지 않는 셔플 큐 방식.
2. 한 문장에 빈칸이 여러 개면 첫 빈칸→둘째 빈칸→셋째 빈칸 순서로 한 개씩 4지선다.
3. 한 문장을 모두 끝내면 다음 문장은 남은 문제에서 무작위 선택.
4. 틀린 횟수/맞은 횟수/정답률을 iPhone 브라우저에 지속 저장.
5. 오답 집중 모드: 오답이 1회 이상인 문제만 모아 다시 출제하고, 오답 횟수가 높은 문제를 더 자주 선택.
6. 과목 구조는 subject 필드를 사용하며 현재는 민법만 수록. 추후 특허법/상표법 JSON 추가 가능.
7. 정답 1개 + 나머지 3개 오답 구조. 현재는 출처에서 확인 가능한 고신뢰 답안을 먼저 넣었고, 미등록 문제는 answers.json / CSV에 빈 상태로 남겨둠.
8. 나중에 정답지를 받으면 answers.json 또는 정답_업데이트용.csv만 교체해서 앱을 업데이트할 수 있음.

중요
- 문제 원문은 '문제 260910.pdf'에서 그대로 추출.
- 답/해설 초안은 사용자가 제공한 '민법 파이널 리뷰 취합본_292.pdf'를 1차 근거로 작성.
- 현재의 답안은 '완성 정답지'가 아니라 검증용 초안이므로 verified=false인 항목은 나중에 반드시 검토.
- 533개 번호 항목 모두 questions.json에 들어 있음.
- 명시적 빈칸이 없는 번호도 하나의 문제 슬롯으로 만들어 나중에 4지선다 답을 붙일 수 있게 설계.

GitHub 업로드
- 이 ZIP을 압축 풀어서 파일 전체를 GitHub 저장소의 루트에 올리면 됨.
- Pages는 main / /(root) 설정.
- index.html을 루트에 둬야 함.

정답 교체
- 정답_업데이트용.csv의 answer_index는 0=①, 1=②, 2=③, 3=④.
- 나중에 네 정답지를 주면 내가 이 CSV/answers.json 형태로 다시 만들어 주면 됨.
