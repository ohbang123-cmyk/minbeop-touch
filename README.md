# 변리사 O/X 문제풀이

민법 + 특허법 개인 학습용 정적 웹앱입니다.

## 기능
- 과목 선택: 민법 / 특허법
- 전체 랜덤 / 미풀이 / 오답 / 자주 틀린 문제
- 1회독 동안 중복 없는 랜덤 출제
- O/X 즉시 채점
- 풀이 표시
- 오답 횟수·정답률·풀이 횟수 저장
- 모바일 반응형
- 별도 서버/DB 없이 브라우저 localStorage 사용

## GitHub Pages 배포
1. GitHub에서 새 repository를 만듭니다.
2. 이 폴더의 파일을 모두 업로드합니다.
3. Settings → Pages → Deploy from a branch → main / root를 선택합니다.
4. 생성된 Pages 주소로 아이폰 Safari에서도 접속할 수 있습니다.

데이터는 브라우저에 저장되므로 같은 기기/브라우저에서 학습 기록이 유지됩니다.
